# Xinyue AI 商业化产品与技术落地计划

更新日期：2026-08-09

## 1. 当前架构

- 前端：Vue 3、TypeScript、Pinia、Vue Router、Vite、Lucide、Naive UI。
- 后端：NestJS、Fastify、Prisma、PostgreSQL、Redis、BullMQ。
- 文件：本地磁盘为默认实现，业务层保留对象存储替换边界。
- 鉴权：HttpOnly Session，邮箱验证码、账户密码、Linux.do OAuth。
- 商业能力：用户、分组、创作点、套餐、充值、兑换码、支付渠道、公告、模型预设、上游渠道、BYOK。

原则：保留现有 Vue + NestJS 主架构，不嵌入第二套管理后台或第二套用户体系。参考项目中的能力按 Xinyue AI 的数据模型和接口重新实现，避免形成无法统一维护的拼装系统。

## 2. 参考仓库审计

### Wei-Shaw/sub2api

可借鉴：账号/渠道分组、模型路由、倍率计费、配额与并发限制、故障冷却、兑换码、公告、运营指标、调用审计、提示词安全审计、Linux.do/OIDC 登录。

落地位置：`ProvidersModule` 增强加权路由与熔断；`ModerationModule` 实现输入审核；商业中心增加渠道成本与毛利；系统状态增加告警和处理记录。

### QuantumNous/new-api

可借鉴：渠道类型与分组、模型价格同步、令牌配额、用户权限、调用日志、渠道测试、Linux.do/OIDC、易支付与 Stripe、审计中间件、多语言管理台。

落地位置：渠道管理统一协议配置；模型预设加入成本价/销售价；支付中心保留易支付并增加对账状态；安全中心统一登录、调用和管理员审计。

### ljquan/opentu

可借鉴：多供应商 Profile、运行时模型发现、图片参数能力矩阵、异步任务、蒙版编辑、批量插入画布、备份恢复、创作工作流。

落地位置：图片模型使用能力驱动参数；生成任务支持重试链和参数快照；后续画布模块支持批量资产、蒙版和工作流模板。

### basketikun/infinite-canvas

可借鉴：无限画布项目的节点交互和 Prompt 库思路，仅作为后续独立引用参考，不接入 Xinyue AI 主工作台。

落地位置：暂不落地，后续如需画布将作为独立产品或外部引用单独开发。

### lobehub/lobehub

可借鉴：模型供应商目录、Agent/助手配置、知识库与文件、插件工具、功能开关、服务端密钥保险箱、内容策略错误处理、多用户数据隔离。

落地位置：模型目录和用户可见能力由后端下发；后续增加助手、知识库和工具权限；内容策略错误统一映射为可理解的前端状态。

### open-webui/open-webui

可借鉴：用户组与细粒度权限、模型访问授权、Prompt/工具/知识库管理、文件权限、审计、管理员配置分区、SCIM/企业身份预留。

落地位置：用户与分组合并成“用户中心”；分组继续承担模型白名单、BYOK、倍率和能力权限；安全中心整合内容审核、登录和操作审计。

### MeowFree/GPT2Image-Pro

可借鉴：图片后端池、优先级/并发/冷却/故障回退、积分幂等记账、易支付履约、公告未读、工单、审核失败关闭策略、图片历史与参数复用。

落地位置：增强现有图片渠道候选和失败切换；支付履约保持幂等；增加工单；审核服务异常时按管理员策略拒绝或记录。ChatGPT Web Cookie、Adobe Cookie、注册机和本地 ONNX 模型不进入 Xinyue AI。

## 3. 统一后台信息架构

1. 运营概览：收入、用户、任务、渠道健康、审核风险和待办。
2. 用户中心：用户列表、用户档案、用户分组、权益策略、封禁与会话撤销。
3. 商业中心：套餐、充值、支付渠道、订单、退款/补单、兑换码、积分流水。
4. 模型中心：上游渠道、模型预设、路由优先级、健康状态、成本与销售定价。
5. 内容运营：灵感、公告、外部入口、后续 Prompt/助手模板。
6. 安全中心：内容审核、敏感规则、登录记录、操作审计、风险处置。
7. 系统设置：站点、注册登录、邮件、默认值、隐私保留、存储与任务队列。

## 4. 分阶段落地

### P0：本轮

- 临时聊天改成居中说明，临时会话退出/删除后回到新对话。
- 用户管理和用户分组合并为用户中心。
- 后台统一保存成功/失败提示、请求进度、已访问页面缓存，减少闪载。
- 内容审核：规则管理、关键词/正则匹配、阻断/记录/转审核、事件列表、处置状态。
- 聊天消息和图片/商品图提示词在进入任务前执行审核。

### P1：商业闭环

- [已完成] 工单与附件、管理员回复、用户未读提醒、负责人和状态流转。
- [已完成] 支付订单对账、人工补单、Webhook 安全重放与幂等状态；支持全额/部分退款、退款审核、Stripe/易支付/外部收银台适配、创作点比例回收和订阅权益回收。
- [已完成] 模型销售点数、创作点价值、模型/路由上游成本、任务价格快照、Token 预授权结算和毛利报表。
- [已完成] 渠道健康探测、熔断、批量检测与人工恢复；新增告警规则、事件、站内通知、签名 Webhook、管理员确认/恢复和规则静默。

### P2：创作能力

- [已完成] 图片能力矩阵：尺寸、质量、输出格式、背景、生成数量、默认值和参考图/蒙版能力由模型预设下发并由后端强校验。
- [已完成] 参考图编辑：校验资产归属后，带参考图的请求发送到 OpenAI-compatible `/images/edits` multipart 接口；无参考图仍走 `/images/generations`，渠道失败继续使用现有 failover。
- [已完成] 蒙版编辑入口：模型启用 `supportsMask` 后前端显示蒙版上传，后端要求参考图并转发 `mask` 文件。
- [已完成] 参数复用：生成资产保存参数快照，前端“用作参考”会恢复尺寸、质量、格式、背景和数量。
- 批量生成和后端池偏好。
- 无限画布不进入当前版本，避免增加主工作台的交互和数据维护成本。
- [已完成] Prompt 模板：管理员 CRUD、分类/排序/发布状态、变量说明、聊天区搜索选择、默认模板种子数据。
- [已完成] 项目工作流和版本历史：步骤配置、自动版本、手动检查点、快照预览、版本恢复和管理员只读审查。
- [已完成] 助手：系统指令、默认模型、前端选择、工具/知识库绑定和发布状态。
- [已完成] 知识库：用户归属、文件绑定、文本提取、基础分块统计和管理员总览。
- [已完成] 工具权限：工具定义、默认关闭、助手白名单、受控 HTTP 调用和调用审计。
- [已完成] 团队空间：团队创建、已注册成员邀请、角色和成员移除。

## 5. 验收规则

- 所有可见按钮必须有真实接口、真实状态变化或清楚的未配置状态。
- 所有写操作必须有成功/失败反馈；高风险操作必须确认并写管理员审计。
- 财务写入必须幂等；密钥只加密保存，读取接口不得返回明文。
- 内容审核默认先审核后创建任务；被阻断内容不得扣点或发送上游。
- 后台模块首次进入显示稳定加载状态，再次进入保留已加载数据并可手动刷新。
- 用户只能访问自己的会话、文件、项目和订单；管理员权限与普通用户入口严格隔离。
