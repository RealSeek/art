# Seedance 视频接入

依据 [Mai API 视频文档](https://api.mai-token.com/docs?family=video)（2026-10-01），OnlyArt 将 Seedance 2.0 / 2.5 接入已有 OnlyCode 密钥和模型同步流程。

部署时执行 `npm --prefix server run prisma:deploy`，升级已有模型的原生视频能力；个人模型自动同步也会补齐旧配置。无需新增渠道类型或直接配置 Mai 密钥，生成仍通过 OnlyCode 的已配置地址及用户密钥调用 `/v1/videos`。

创作页支持固定／自动时长、多图及音频参考、公开视频 HTTPS 地址、首帧／首尾帧、生成音频、水印、尾帧链接；2.5 另支持视频编辑、延长和 MP4／MOV。2.0 提供 4–15 秒和 480p／720p／1080p／4k，2.5 提供 4–30 秒和 480p／720p／1080p。4k 是否可用以 OnlyCode 账户价格配置为准。

图片与音频通过原生 `content` 的 Data URL 提交；参考视频使用公开 HTTPS URL，不支持视频 Base64。首尾帧按图片顺序发送 `first_frame`、`last_frame`。2.5 首帧、编辑和延长需要 `adaptive`，编辑需要自动时长。参考视频／音频的总时长及素材内容限制由上游校验。

成功后读取 `metadata.url`、`result.url` 或原生 `content.video_url` 并立即保存视频到 art 文件库。上游真实用量和尾帧链接保存在生成文件元数据中；尾帧链接仍受上游有效期约束。下载内容接口支持经过公网地址校验的跳转，API 密钥不会随跳转发送。内联图片／音频不写入任务记录或生成文件元数据。

OnlyCode 按真实输出 Token 结算；个人密钥调用继续由 OnlyCode 扣费，art 不将请求秒数换算成虚构 Token。art 平台模型仍使用已有创作点售价配置。

创建超时、5xx、缺少任务编号等结果不明的情况进入对账流程，不自动重建任务。查询临时错误继续查询原任务；明确失败立即停止，保留上游错误信息和服务端任务编号以便排查。

验证覆盖本地 HTTP 模拟的创建、轮询、下载、素材顺序、音频提交及浏览器设置提交。没有使用真实密钥执行付费生成。
